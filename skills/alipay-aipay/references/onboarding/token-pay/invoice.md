# 数电发票 · 商家办理

核对[发票产品资料](https://opendocs.alipay.com/pre-open/0k3k6p?pathHash=6b81e5a4)和商户已有控制台证据：商户应用已具备发票产品权限、销方税号对应签约主体、开票服务授权适用。支付产品签约或用户完成订阅付款，均不能替代发票准入。
本包提供办理指引；不编造开通、登录或查签约 API，不自动投递线索或代签。登录与身份验证由商家在官方入口完成。按需核对服务商代调用的正式契约，不能直接采用 B2B 或订阅身份模型。
工程实现、开票/红冲、查询下载与通知见[发票接入](../../integration/token-pay/invoice/integration.md)；本地可模拟，商家明确获准的该产品非生产环境可联调。仅收到申请回执不等于已开票，不能用订阅时钟验证发票。
