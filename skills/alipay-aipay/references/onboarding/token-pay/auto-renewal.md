# 自动续购 · 商家办理

余额低于用户设定阈值时按其协议续购，不是每月定时扣款。区分商家的产品准入和每位终端用户在支付宝确认扣款协议。
1. 根据旧接入资料，自动续购定向邀约开放，可涉及企业、个人或个体工商户；由对接业务人员和当期官方资料确认当前商家是否在名单、已获哪种应用权限及相应费率。不要用周期订阅的一站式申请条件替代。
2. 已有经营主体及应用时，核对其自研应用或已授权第三方应用与对应产品；第三方代调用必须对应实际商户。调查问题或开发代码时无需先代商家办理。
3. 本包可以说明办理步骤、核对商家已有的脱敏凭据；不能自动投递线索、代提交开通或从资料推断已生效。用户首次签协议、扣款预通知和扣款结果分开看。
4. 开发走[自动续购](../../integration/token-pay/auto-renewal.md)。以产品准入、实际协议及结果为准；当前包仅用本地模拟验证，不启动周期订阅测试时钟。
