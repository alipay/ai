# 按明确请求处理的专题
本页只用于用户明确提出下列具体身份、操作或受限模式时匹配；不作为常规订阅开发的必读资料，不主动展示其他专题。咨询或给出名称不是准入或执行授权。
| 当前用户的具体问题 | 只加载相应资料 |
| --- | --- |
| 明确问第三方应用代调用、ISV 授权、代商户传 `app_auth_token` 或服务商通知 | [服务商代开发](service-provider-mode.md)。B2B 仅支持自有应用；其他子能力使用各自的授权规则。 |
| 点名 Submode、订阅子模式或其 create/modify 方法 | [对应专项说明](submode.md)；先核实定向准入。未点名时不主动提及、猜测或读取。 |
| 点名关闭创建、升级或扩容的待支付单，或指名 apply.close | 默认不支持；先核实该商户已获明确邀约后才读[定向支付单关闭](restricted/close-pending-order.md)。不用于普通取消订阅。 |
| 明确点名 MERCHANT_DEDUCT、希望了解已有非托管扣款上下文 | [存量非托管接口、预通知和字段参考](restricted/merchant-deduct.md)。仅用于内部理解或识别已点名的已有接入，不推荐、不据此提供扣款执行；联系对接人核对权限。 |
| 商家明确问生产环境测试客户推进、账号绑定，或解读已有生产推进记录 | [生产测试客户操作说明](test-advance.md)：只读指导和核对证据，不执行生产推进或真实扣款。需要无真实资金联调时用[订阅沙箱](sandbox/sandbox-integration.md)。 |
