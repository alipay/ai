# 从支付宝 AI 付官网查证

从[官网索引 llms.txt](https://aipay.alipay.com/llms.txt)找与问题相关的详情页。产品不明确时先看产品矩阵，索引未覆盖时可继续在官网站内搜索。沿官方链接优先读 Markdown，也可读同一产品的 HTML。页面标题与对客名称不一致时，结合索引分组、页面路径和正文确认产品。包内产品沿用能力表中的名称。答复附上支撑结论的详情页，涉及开放对象或办理条件时说明适用范围。

流程中途也可查证，沿用已确认的产品、工程和环境。页面超时可换一种只读方式重试同一链接。仍无法核实时，说明是页面未能读取，还是已读的官方资料没有说明。

按用户原来的请求继续。只问产品时，给出有出处的答案。用户已明确要求开发或开通，且[本 Skill 的能力表](product-decision.md)支持该操作时，进入对应产品流程。只有办理指引时给出办理入口，只有公开资料时说明已核实的范围。
